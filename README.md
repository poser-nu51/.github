## Figure Overview

Poser is designed around ready-to-use, fully rigged 3D human and creature figures, letting artists focus on posing, dressing, and rendering rather than modeling from scratch. A rich content library provides characters, clothing, hair, and props.

Its intuitive posing controls and inverse kinematics make it easy to set natural stances, expressions, and gestures, while a built-in animation timeline supports walk cycles and movement without complex rigging knowledge.

Popular with illustrators and storyboard artists, Poser renders finished figures for reference, comics, and concept work, offering a fast path from empty scene to a fully staged, lit character image.

## Getting Started Playbook

Load a figure from the library, then use the posing dials or direct manipulation to set the stance while inverse kinematics keeps hands and feet planted naturally. Add expressions and morphs to shape the character.

Dress the figure with conforming clothing and hair, set up lights, and frame the camera. Pose additional frames on the timeline for animation if needed, then render the scene to produce a finished character image or reference.
